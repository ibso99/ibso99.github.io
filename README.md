# Ibsa Nuru Portfolio Website

A polished, static portfolio website for Ibsa Nuru's CV, GitHub work, credentials, selected projects, and professional contact links.

## What is included

- `index.html` — complete one-page portfolio.
- `styles.css` — responsive, accessible, dark/light portfolio design.
- `script.js` — theme toggle, mobile navigation, and project filtering.
- `assets/Ibsa_Nuru_CV.pdf` — CV download asset.
- `assets/AWS_AI_Practitioner_Challenge_Certificate.pdf` — certificate asset.
- `assets/favicon.svg` and `assets/og-image.svg` — branding assets.
- `DEPLOYMENT.md` — quick publishing steps.

## Recommended CV line

Portfolio: `https://ibso99.github.io/ibsa-portfolio/`

Use the exact URL that GitHub Pages gives you after deployment.

## Edit before publishing

1. Replace the LinkedIn placeholder if you want a LinkedIn link in the header or contact area.
2. Add live demo URLs for projects when available.
3. Confirm whether you want your phone number visible on the public website. It is intentionally not printed on the page body, but the CV PDF contains your contact details.
4. Update the portfolio URL in the CV after deployment.
