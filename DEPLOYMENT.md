# Deploy to GitHub Pages

## Option A — Project site under your existing GitHub account

1. Create a new public repository named `ibsa-portfolio`.
2. Upload all files from this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/root`, then save.
6. Your site will usually be available at:

```text
https://ibso99.github.io/ibsa-portfolio/
```

Add that link to the **Portfolio** field in your CV.

## Option B — Main personal website

1. Create a public repository named exactly `ibso99.github.io`.
2. Upload all files from this folder to the repository root.
3. GitHub Pages will publish it as:

```text
https://ibso99.github.io/
```

This is cleaner for a CV because the URL is shorter.

## Best recommendation

Use **Option B** if you want the most professional CV link. Use **Option A** if you want to keep this as one project among many.
